## 🏃 Nike Landing Page - Just Do It


### Este projeto é uma landing page fictícia para a marca Nike, desenvolvida com HTML, CSS e Font Awesome. Ele simula uma vitrine moderna de produtos com foco em design, responsividade e experiência do usuário.

<br>
🔍 Visão Geral
A página oferece uma interface limpa e atraente para apresentar uma coleção de tênis da Nike, além de seções como:

Home: Apresentação visual impactante da coleção.

   Produtos: Cards de produtos com preços, avaliações e botão de "Adicionar ao Carrinho".

   Sobre: Informações adicionais com troca interativa de imagens.

   Avaliações: Comentários e classificações de clientes fictícios.

Serviços: Destaques dos serviços oferecidos (incompleto no código fornecido).

### 🛠️ Tecnologias Utilizadas
<br>

 - HTML5: Estrutura da página.
 
 
 - CSS3: Estilização visual.

    - Font Awesome: Ícones de alta qualidade.

     - Responsividade Básica: Via meta tags e layout em blocos.
